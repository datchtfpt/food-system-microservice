1. TỔNG QUAN HỆ THỐNG
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Hệ thống gồm 3 module chạy độc lập:

  Client (Postman / Frontend)
       gọi vào port 8080
  [foody-gateway]        :8080
       /restaurant-service/**  → forward → :8081
       /food-service/**        → forward → :8082
  [restaurant-service]   :8081
  [food-service]         :8082

  - Spring Boot 4.1.0
  - Spring Cloud 2025.1.2
  - Database: Microsoft SQL Server (port 1433)
  - ORM: Hibernate (Spring Data JPA)
  - Build tool: Maven

2. MODULE: foody-gateway
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Port     : 8080
Package  : fu.de190913.gateway
Framework: Spring WebFlux (reactive, non-blocking)

[Dependencies pom.xml]
  - spring-boot-starter-webflux
  - spring-cloud-starter-gateway-server-webflux
  - spring-cloud-starter-openfeign
  - lombok
  - springdoc-openapi-starter-webflux-ui:3.0.3

[application.yml]
  server:
    port: 8080
  spring:
    application:
      name: foody-gateway
    cloud:
      gateway:
        routes:
          - id: restaurant-service
            uri: http://localhost:8081
            predicates:
              - Path=/restaurant-service/**
            filters:
              - RewritePath=/restaurant-service/(?<segment>.*), /${segment}
          - id: food-service
            uri: http://localhost:8082
            predicates:
              - Path=/food-service/**
            filters:
              - RewritePath=/food-service/(?<segment>.*), /${segment}
  springdoc:
    swagger-ui:
      urls:
        - name: Restaurant API
          url: /restaurant-service/v3/api-docs
        - name: Food API
          url: /food-service/v3/api-docs

[Cấu trúc package và class]

  └── config/
      ├── GatewayConfig.java
      │     @Configuration
      │     @Bean RouteLocator customRouteLocator(RouteLocatorBuilder builder)
      │       Cùng chức năng với application.yml nhưng viết bằng Java code:
      │       .route("restaurant-service", path=/restaurant-service/**, rewrite, uri=8081)

              → allowedMethod("*")
              → allowedHeader("*")

              → registerCorsConfiguration("/**", corsConfig)

5. QUY TẮC QUAN TRỌNG KHI TẠO SERVICE MỚI TƯƠNG TỰ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[A] ENTITY - @Column mapping
  - Hibernate SpringPhysicalNamingStrategy: tự convert camelCase → snake_case
  - Chỉ thêm @Column(name="...") khi tên cột DB KHÁC với kết quả tự convert
  - Ví dụ: "owner" → Hibernate đoán "owner", DB là "owner_name" → cần @Column
  - Ví dụ: "openDate" → Hibernate đoán "open_date" = đúng → không cần @Column
  - KHÔNG viết @Column(name="camelCase") vì Hibernate dùng đúng tên đó (sai)

[B] DTO
  - Nếu dùng @Builder → phải thêm @NoArgsConstructor + @AllArgsConstructor
    Lý do: Jackson cần no-arg constructor để deserialize JSON → object
  - Dùng @Data hoặc @Getter+@Setter cho DTO nhận request body

[C] Controller
  - Dùng ResponseEntity.ok(apiResponse) KHÔNG dùng ResponseEntity.status(businessCode)
    Lý do: getStatus() trả về 1,2,3,4 → không phải HTTP status code hợp lệ → lỗi

[D] Service createXxx
  - KHÔNG validate null cho field Id (auto-generated, client không truyền)
  - Chỉ validate các field bắt buộc theo business

[E] SwaggerConfig - BẮT BUỘC mỗi service
  @Bean OpenAPI customOpenAPI()
    .addServersItem(new Server().url("/<prefix-của-service-trong-gateway>"))

[F] application.properties - BẮT BUỘC
  server.forward-headers-strategy=framework
  (Swagger cần biết request đến qua gateway prefix nào để generate URL đúng)

[G] Gateway - thêm route khi có service mới
  Thêm vào application.yml VÀ GatewayConfig.java:
    path: /<tên-service>/**
    rewrite: cắt bỏ /<tên-service>/ prefix
    uri: http://localhost:<port>

[H] @Table name - phải khớp chính xác tên bảng trong DB
  Kiểm tra: SELECT TABLE_NAME FROM INFORMATION_SCHEMA.TABLES

6. API RESPONSE FORMAT CHUẨN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Single object:
  { "status": 1, "message": "...", "data": { ... } }

Danh sách (PageDTO):
  {
    "status": 1,
    "message": "Success",
    "data": {
      "size": 10, "page": 0,
      "totalPages": 5, "totalElements": 47,
      "first": true, "last": false,
      "content": [ ... ]
    }
  }

Status code convention:
  1 = success
  2 = exception (catch block)
  3 = required field is null
  4 = entity not found
